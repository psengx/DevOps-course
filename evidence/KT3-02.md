# KT3-02


1. Файл `student-ci.yml`

```yml
name: Student CI
on:
  push:
  pull_request:
permissions:
  contents: read
jobs:
  test:
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@d23441a48e516b6c34aea4fa41551a30e30af803 # v6
        with:
          persist-credentials: false
      - uses: actions/setup-python@ece7cb06caefa5fff74198d8649806c4678c61a1 # v6
        with:
          python-version: '3.13'
      - run: python --version
      # K3-03: add the command which actually runs tests/test_app.py.
  # K3-04: add a separate build job, needs: test, checkout and docker build.
```

Здесь можно увидеть, что workflow будет автоматически срабатывать при push и pull_request

## Объяснение job/step

Job является группой шагов (step), которые выполняются в рамках workflow
