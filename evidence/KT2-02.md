## Создание файла `lab/Dockerfile`

``` Dockerfile
FROM python:3.13-slim-bookworm
WORKDIR /app
ENV PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1
COPY app.py index.html ./
RUN mkdir /data && chown 10001:10001 /data
LABEL course.student="06052007"
USER 10001:10001
EXPOSE 8000

```



## Проверка понимания

Почему EXPOSE не заменяет -p? 
* **`EXPOSE`** в Dockerfile сообщает, какой порт приложение внутри контейнера слушает по умолчанию. Сама по себе эта инструкция не открывает доступ к порту снаружи хост-машины. 
- **`-p` (`--publish`)** при вызове `docker run` выполняет **реальное перенаправление портов** на сетевом уровне хоста. Она связывает внешний порт `8081` с внутренним портом контейнера (`8000`), делая приложение доступным из внешней сети или с localhost.
Без `-p` не выйдет достучаться до приложения через `localhost:8081`, даже если `EXPOSE 8000` прописан в Dockerfile.
