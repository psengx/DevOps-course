2. Далее по заданию выполнена команда `docker compose stop web` для остановки контейнера web, в результате страница `http://localhost:8080/` не загружалась:

![hostDead.png]()

4. Запуск контейнера web с помощью команды `docker compose start web`. Страница снова загружается, заявки отправляются:
  
![hostWorks.png]()

**Проверка понимания:** Удаляется ли образ при остановке web? Нет, не удаляется, так как мы  просто останавливаем контейнер web командой `stop`, а сам контейнер является лишь экземпляром образа, поэтому даже его удаление не вызовет удаление образа.
